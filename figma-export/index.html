Can you explain how the QLoRA training pipeline works in Sovereign Coder?
Qwen2.5-Coder-32B
QLoRA (Quantized Low-Rank Adaptation) is a parameter-efficient fine-tuning approach that keeps the base model in 4-bit NF4 quantization while training small LoRA adapter weights. This lets you fine-tune a 32B model on a single 24 GB GPU.
from peft import get_peft_model, LoraConfig
# rank=32, target attention projections
config = LoraConfig(r=32, lora_alpha=64, target_modules=["q_proj", "v_proj"])
model = get_peft_model(base_model, config)
